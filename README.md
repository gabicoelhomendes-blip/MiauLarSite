
# MiauLarr

Projeto acadêmico desenvolvido para a disciplina de
Análise e Projeto de Sistemas.

O MiauLarr será uma plataforma web para facilitar
a adoção responsável de gatos.

## Objetivo

Permitir que usuários consultem gatos disponíveis,
criem contas e solicitem adoções.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- React
- Node.js
- SQLite
